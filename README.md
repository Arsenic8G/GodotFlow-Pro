## ⚡️ The New Standard

Manual 3D-to-engine exports are obsolete. No more renaming suffixes by hand, configuring import settings, or cleaning control bones.

| Traditional Way | GodotFlow Pro |
| :--- | :--- |
| ⏱️ 5–10 minutes tweaking GLTF export tabs | ⚡️ **1 click (`📦 Selected` or `🚀 Sync All`)** |
| 🏷️ Manual `-convcolonly` / `-colonly` renaming | 🪄 **Auto-generated, decimated collision shapes** |
| 🦴 IK bones cluttering the Godot scene tree | 🧹 **Automatic deform-only bone filter** |
| 📦 Single heavy GLB file with buried animations | 🎭 **Split `Mesh@Action-loop.glb` animation libraries** |

## 🕹️ Quick Start

1. **Bind Root:** Press `N` $\to$ **Godot** tab $\to$ set your target project folder (`res://`).
2. **Configure Once:** Pick your collision type (Convex/Trimesh) and toggle animation splitting.
3. **Hit Sync:** Select models and hit **`📦 Selected`** or **`🚀 Sync All`**.

## 📥 Get Started in Seconds

1. Grab **[`godotflow_pro.zip`](https://github.com/Arsenic8G/godotflow-pro/releases/latest)**.
2. In Blender: `Edit` $\to$ `Preferences` $\to$ `Get Extensions` (or `Add-ons`).
3. Click the top-right menu $\to$ **Install from Disk...** and pick the `.zip`.
4. Press `N` in the 3D Viewport. You’re ready.
